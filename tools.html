// TOOL 01 — SERIAL-DATA-MIDI TRANSLATOR — 05.2019

About:

A patch developed in Pure Data that allows Arduino boards to be quickly and easily connected to any software capable of receiving and interpreting MIDI signals.

Created in May 2019 for Sophie's Fall, a sound installation by Nami Salim.

// TOOL 02 — OSC SERVER / CLIENT — 03.2021

About:

A tool developed for creators who need a free and accessible way to synchronize videos across multiple devices. It allows users to perform perspective corrections, adjust projections, and blend images across multiple projectors.

Created in March 2021 for The Escapist, a 360-degree panoramic video installation by Pavel Méndez.
